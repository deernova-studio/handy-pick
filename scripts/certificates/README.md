# Apple public intermediate certificate

`DeveloperIDG2CA.cer` is Apple's public Developer ID G2 intermediate certificate,
downloaded from https://www.apple.com/certificateauthority/DeveloperIDG2CA.cer.
It contains no private key or user credential. It is imported only into the
temporary signing keychain; no custom trust settings are installed.
