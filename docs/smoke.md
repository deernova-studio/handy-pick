# HandyPick 冒烟用例

本仓库仅维护以下 10 条用户流程／交付冒烟，不维护单元测试、mock 测试或覆盖率门禁。执行时记录版本、系统、结果（通过／失败／未执行）及必要说明，不把编译成功当作交互验收通过。

`one run handy-pick:check` 或 `one run handy-pick:smoke` 只执行 SM-01。SM-02–SM-09 使用已授权的真实安装版和测试内容；不把开发包覆盖到日常安装版，不向真实联系人发送测试消息。SM-10 在正式发版时执行。

| 编号 | 流程与操作 | 预期结果 |
| --- | --- | --- |
| SM-01 | 执行构建冒烟命令，走实际 `package.sh --dev` 打包流程。 | 脚本语法有效；arm64 Release 编译成功；开发 `.app` 包含图标及本地化资源，Info.plist 和签名完整性校验通过。开发包不代表已公证。 |
| SM-02 | 启动安装版，查看菜单栏并打开设置；暂停后触发，再恢复触发，退出重启。 | 仅一个实例，无多余主窗口；暂停不触发，恢复可触发；按键设置保留；缺权限时明确提示；完成授权后自动恢复监听，用户主动暂停时保持暂停。 |
| SM-03 | 保持其他应用在前台，将鼠标移到桌面（不先左键点击）双击中键框选，拖动选区内部，拖动边缘调整，双击选区内部确认；另起一次截图按 Esc；屏幕捕获等待期间暂停并重新启用。 | 移动和缩放正常、工具栏跟随；确认后剪贴板得到对应图片；取消不覆盖原剪贴板；暂停后旧任务不能弹出选区。 |
| SM-04 | 截图后分别划线、画方框、画圈、画箭头、输入文字，撤销一次，再用勾号确认。 | 标注位置正确，反向拖动方框与四个方向箭头正常；撤销移除最后操作；复制后的图片包含剩余标注，且没有工具栏。 |
| SM-05 | 在文本编辑的测试文档选中文字后双击中键复制，再清除选区、点入正文双击粘贴；截图后同样粘贴图片。 | 文字与图片均正确粘贴，出现复制反馈，不误进入截图。对暴露为可编辑 AXGroup 的输入区，不能识别时不误截图；终端复制过程中如有其他来源写入剪贴板，不得自动执行已排队的粘贴；涉及 Codex／终端等兼容修改时分别记录真实应用结果，不以文本编辑通过替代。 |
| SM-06 | 组合键分别绑定 Shift+P（复制／截图）和 Control+Option+V（粘贴），选字后把鼠标移出编辑区再按复制键、无选字截图、焦点粘贴；快速连续按复制键和粘贴键，另试等待时暂停／切换前台／在同一应用从输入框 A 切到 B；再设置相同组合；切回双击并绑定普通 P，在输入框打字。 | 独立组合按一次执行指定动作；键盘复制按焦点选区，粘贴不依赖鼠标位置；快速复制后粘贴只执行一次且使用新复制内容；复制失败或等待取消时不粘贴旧内容；等待期间换输入框、点击或按 Tab 后不执行迟到粘贴；相同组合只执行一次自动判断；两行设置可独立保存并在重启后保留；双击按两次触发，普通 P 在已识别输入框正常输入及长按。 |
| SM-07 | 连续复制图片及文字，打开历史，切换全部／图片／文字，点击记录，右键删除单条、清空，再重启。 | 筛选正确；点击能重新复制；最多显示三行，超出可滚动；删除、清空及重启清理生效；无内容时不显示历史区。 |
| SM-08 | 从历史放大有文字的测试图片，直接拖选文字复制；切换标注、退出标注、撤销后再选字；打开长文字预览；保持预览开启，点击其他应用，再回到预览。 | 图片默认可选字；标注与选字能切换，未编辑时返回选字复用缓存，编辑或撤销后重新识别；慢识别显示原生小型提示且 Esc 可退出；未选字时确认复制图片；文字预览可滚动选择；其他应用快捷键可用，预览重新获得焦点时快捷键不干扰编辑。 |
| SM-09 | 在浅色和深色外观下查看菜单栏与设置，逐项切换分类，并检查空历史和单行历史。 | 菜单栏图标清楚；分类图形选中前后大小一致；设置行对齐；浮层无箭头，高度随内容变化。macOS 14 的验收需单独记录。 |
| SM-10 | 正式发版执行 One release，检查产物并验证 GitHub Release 资产。 | 应用及 DMG 的 Developer ID 签名、公证、附票和 Gatekeeper 校验通过；本地与上传文件 SHA-256 一致；tag 对应发布提交。 |

## 已知兼容限制

- 当前这台 Mac 的微信 4.2.0 未向 AX 接口暴露聊天输入框，中键可能再次进入截图；暂用 Command+V。用户已要求暂不处理，不将其记为通过。
- Codex 内嵌终端与 macOS 14 实机未完整验收；必须记录真实结果，不能由独立示例窗口或构建成功推断通过。
